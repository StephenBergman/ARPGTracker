# Install ARPG Seasons

## Local Windows package

1. Extract the entire `ARPG-Seasons-<version>-Windows-x64.zip` archive.
2. Run `ARPG-Seasons-<version>-x64-local-setup.exe`.
3. Follow the setup wizard, then open **ARPG Seasons** from the Start menu.

The installer installs for the current Windows account; administrator access is normally unnecessary. It includes the application, so Node.js, Rust, and developer tools are unnecessary. Use Windows 10 or 11 on an Intel/AMD 64-bit computer. If WebView2 is missing, setup may need internet access to install it.

This is the standard client. The maintainer's personal reviewer is a separate application and is not included.

Local packages lack a Windows publisher certificate. Windows may show SmartScreen; verify the file's origin before using **More info → Run anyway**. Respect any policies on organization-managed devices.

## Everyday use

Choose a game and open Settings to customize compact mode, always-on-top, and launch with Windows. Drag the header to move the window. Close hides the app to the tray; choose **Exit** from the tray to quit.

Season data updates automatically when online. Use **Settings → Season data → Refresh season data** for an immediate check. Offline use keeps the last available information.

## Upgrade or uninstall

Exit the app through its tray menu before running a newer installer. Install over the existing standard client to upgrade. Local installers are for manual installation; they are not signed updater artifacts. Future signed public releases can be offered through the app's update controls.

To uninstall, exit the app and use **Windows Settings → Apps → Installed apps → ARPG Seasons → Uninstall**.
